Changelog

v1.4.1 Latest

  • Added a Save button to the active-session card to store the current token in the vault instantly.
  • Removed the duplicate full-width "Add Session" button — the Vault now has a single Add action.
  • Added visible Copy and Details buttons (+ More menu) on every vault card.
  • Account cards now always show a picture (initials fallback while the avatar loads).
  • Bundled official extension icons (16/32/48/128).
  • Added this public release, download site and packages.

v1.4.0

  • Material 3 redesign of the popup (now-playing card, two-row cards, bottom nav, FAB).
  • Real tab switching across Vault / Import / Settings / Lock.
  • Strict discord.com-only launch matching to prevent token injection on malicious pages.
  • Manrope type system across the UI.

Older versions

  • Core vault, add/verify/export, copy token, launch & switch flows.
