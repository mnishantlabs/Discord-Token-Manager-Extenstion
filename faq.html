FAQ

Is my data uploaded anywhere?
No. Tokens, notes and settings are stored only in your browser's local storage. There are no accounts, no servers and no telemetry. Token validation calls go directly to Discord's API from your browser.
Is this safe / against Discord's rules?
Token-based authentication can violate Discord's Terms of Service and may lead to an account action. This is a tool for your own personal, low-volume use. Use it at your own risk; it is not affiliated with Discord.
Why is there no "Install from the Chrome Web Store" button?
Publishing to the Chrome Web Store or Firefox AMO requires developer accounts, store review, and may be rejected for token managers. This project ships as load-unpacked / temporary add-on packages instead — fully functional, just installed by hand.
Does it work on Edge / Brave / Opera?
Yes. They are Chromium-based and load the MV3 chrome package the same way Chrome does. Use the Chrome zip.
The extension resets after restarting Firefox.
Temporary add-ons are removed when Firefox closes. Keep a dedicated profile or re-load after startup. On Chrome, unpacked extensions persist until you remove them.
How do I back up / restore my sessions?
Use the Backup chip in the Vault to export a JSON file. Restore it later on the Import tab by pasting the JSON.
An account shows no picture / name yet.
Details are fetched when a token is verified or saved. If the network call fails, the card falls back to initials. Press Verify to refresh.
How do I update to a new version?
Download the new zip and re-load the unpacked folder. Your saved data lives in the browser and survives updates.
