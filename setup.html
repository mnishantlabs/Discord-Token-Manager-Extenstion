Step by step

Setup & install

Loading the extension takes under a minute. Because this is a private-build extension, you install it as an unpacked (temporary) add-on.

Chrome · Edge · Brave · Opera · Arc

These are all Chromium browsers and use the exact same steps.

1

Download the Chrome package

From the Download page, grab the Chrome & Chromium zip and unzip it somewhere you'll remember (e.g. Downloads). Keep the chrome folder intact.

2

Open the extensions page

  • Chrome — chrome://extensions
  • Edge — edge://extensions
  • Brave — brave://extensions
  • Opera — opera://extensions
  • Arc — Settings → Extensions
3

Turn on Developer mode

Use the toggle in the top-right corner of the extensions page.

4

Click "Load unpacked"

Select the unzipped chrome folder (the one containing popup.html and manifest.json — not the zip itself).

5

Pin it & open

The Discord Token Manager icon appears in your toolbar. Click it to open the popup and add your first session.

Note: because Developer mode is enabled, Chrome may show a "Disable developer mode extensions" warning — that's normal. On some managed devices this mode is blocked by the admin.

Firefox

Firefox loads private-build extensions as a temporary add-on (it stays active until you close Firefox).

1

Download the Firefox package

Grab the Firefox zip from Download, unzip it, and keep the firefox folder intact.

2

Open the add-on debugging page

Type about:debugging#/runtime/this-firefox in the address bar and press Enter.

3

Load Temporary Add-on

Click the Load Temporary Add-on… button and select firefox/manifest.json.

4

Pin & open

The extension icon appears in the toolbar. Click it to open the popup.

Temporary add-ons reset on restart. To avoid re-loading after every restart, use a dedicated Firefox profile that you keep open, or sign it via AMO (for private, personal use).

Using the extension

Add a session

Click the Add chip in the Vault and paste a token, or use the Save button on the active-session card.

Switch / launch

Press Switch on a saved session — a discord.com tab is opened and logged in automatically.

Verify

Press Verify on a card or Verify all to check token validity.

Backup

Use Backup in the Vault to export a JSON file, ready to restore later.
